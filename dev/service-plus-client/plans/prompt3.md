# Modification of extended warranty system
- At present Extended warranty system is implemented and working. It is in Menu Item Custom > Extended warranty
- It was developed based on plans/prompt.md file. The complete implementation is in files plan-ew.md, plan.md and plan1.md. you can read them.
- Instead of making changes, you can delete the entire extended warranty flow from server, client and suggest necessary changes in DB and create a new plan.
- Major changes are required in functionality of extended warranty system. Following is the new context:
    - Data Model
        - Add new column is_closed
        - All the Lost, Won and Cancelled leads are is_closed true
    - Any lead can have one of following states. State can be changed by the user through actions which do state transitions.
        - New_Lead
            - 31-60 days
            - 8-30 days
            - 0-7 days
            - Overdue
        - Message_Sent
            - Delivered
            - Read
            - Fail
        - Interested (Had clicked the button)
        - In_progress
            - Stage_1
            - Stage_2
            - Stage_3
        - Lost
        - Won
        - Cancelled
    - Lost / Won / Cancelled are is_closed = true otherwise the lead is active
    - Possible state transitions
        - New Lead -> Message Sent, In_progress, won, lost, cancelled
        - Message Sent -> Interested, In_progress, won, lost, cancelled
        - Interested -> In_progress, won, lost, cancelled
        - In_progress -> won, lost, cancelled
        - Lost -> in_progress, won
        - cancelled -> in_progress
- UI design: Two tabs: Dashboard: Details
    - Dashboard
        - At the top there will be a nice, colored graphics, depicting the state transitions possible. Not clickable. A simple graphical workflow giving an idea of state transition flow based on above state transitions. It can use simple flow chart components or svg graphics or whatever you think is best. Make it colorful and attractive.
        - Below the flow chart there will be following sections. Each section will have a counter with bold large font and colored border. Border color will be same as the color mentioned in parentheses.
            - Lead Pipeline: Having following clickable cards with values
                - New_Lead 
                    - 31-60 days (colored green)
                    - 8-30 days (colored blue)
                    - 0-7 days (colored orange)
                    - Overdue (colored red)
                    - All (colored green)
                - Message_Sent 
                    - Delivered (colored green)
                    - Read (colored blue)
                    - Fail (colored red)
                - Interested (colored orange)
                - In_progress 
                    - Stage_1 (colored green)
                    - Stage_2 (colored blue)
                    - Stage_3 (colored orange)
                - Won (colored green)
                - Lost (colored red)
                - Cancelled (colored red)
                - Clicking of above cards will lead to a drill down page with a prominent back button which will take to the dashboard. Drilldown page will have a grid showing corresponding values.
                - Towards the end of each row there is actions menu (3 dots), clicking which will show dropdown menu with valid state transitions. Clicking on a state transition will change the state of the lead and update the grid and dashboard values.
                - New lead and Message_sent stage allows to send mmessages. Whatsapp messages can be sent by drop down action item, when valid then enabled. Or user can select multiple rows together to send all messages at once.
                - Only new_lead and Message_sent state can be sent new messages
                - In progress will have follow up actions which will open  modal window (outside click non closable), where user can input follow up actions as text, schedule a follow up date and time, or more items.
            - Message summary
                - today, week and month, over a month old
                    - Read
                    - delivered
                    - fail
            - Overall Summary count, today, week and month, over a month old
                - leads, 
                - messages sent
                    read, delivered, fail
                - interested
                - Won
                - Lost
                - Cancelled
    - Details
        - A grid showing all leads sorted with last entered at top, all columns, state and possible actions at right.
